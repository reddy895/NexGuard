# NexGuard — Edge AI CCTV Surveillance System

![NexGuard Banner](https://img.shields.io/badge/NexGuard-Edge_AI_Surveillance-blue)
![Version](https://img.shields.io/badge/Version-0.1.0_Phase_1-green)
![License](https://img.shields.io/badge/License-MIT-purple)

NexGuard is an Edge AI CCTV surveillance system designed for real-time computer vision detection on edge devices. In its final evolution, NexGuard will detect road accidents, verify incident severity, and automatically alert local emergency dispatch units, hospitals, and police.

> **Current Phase Scope (Phase 1):**  
> Terminal-based edge AI detection using YOLO. Reads video, webcam, or image inputs, performs real-time object detection, displays live stats (FPS, object counts, device mode), and allows interactive snapshot captures.
